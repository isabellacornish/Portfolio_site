CHARACTER DESIGN & ILLUSTRATION PORTFOLIO

HOW TO VIEW
Double-click index.html. It opens in any web browser. No install needed.

HOW TO ADD YOUR ARTWORK
Put your images in the folders inside "images", using the names in each
PUT-IMAGES-HERE.txt file. Refresh the page and they appear. Any image that is
missing just shows the placeholder character.

  images/carousel  -> slide-1 to slide-4   (top of page, square)
  images/work      -> work-1 (wide, added), work-2 and work-3 (square)
  images/process   -> turnaround-1 to -3, expression-1 to -4
  images/about     -> profile              (About me, square)

HOW TO SHARE
Zip the whole "portfolio" folder and send it. Keep index.html and the
"images" folder together. The text fonts need internet; offline, the page
falls back to standard fonts and still works.

FONT: Object Sans -> put ObjectSans-Bold.woff2 or .otf in the "fonts" folder (see PUT-FONT-HERE.txt).
